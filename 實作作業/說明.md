# 實作作業（前端原始碼）

這裡是介面的**原始檔**，拆成三個檔案方便維護：

| 檔案 | 內容 |
|---|---|
| `index.html` | 頁面結構（含內嵌的 logo data URI 與 favicon） |
| `styles.css` | 介面樣式（深色主題，設計語言參考 `設計素材/visual.png`） |
| `app.js` | 前端邏輯：圖片上傳、OCR、法規比對、陳情信生成 |

## 改完一定要建置

實際執行的是 `../static/index.html`，那是把上面三個檔**合併內嵌**後的單一檔案。
直接改 `../static/index.html` 會在下次建置時被覆蓋，請改這裡的原始檔。

```
python build.py
```

然後在瀏覽器按 Ctrl + F5 重新整理即可看到效果（介面改動不需要重開 exe）。

## 為什麼不能直接用三個檔案？

`違規廣告快篩.exe` 內建的 HTTP 伺服器只處理三個路徑：

| 路徑 | 回應 |
|---|---|
| `/` 與 `/index.html` | 讀 `static/index.html` 回傳 |
| `/api/status` | 回傳是否已設定 AI 金鑰 |
| `/api/analyze` | 執行 OCR 與法規比對 |

其餘路徑（包含 `/styles.css`、`/app.js`、`/logo.png`、`/favicon.ico`）**一律回 404**。
這是編譯進 exe 裡的行為，改不了，所以：

- CSS 與 JS 必須內嵌 → 由 `build.py` 處理
- 圖片（logo、favicon）必須用 data URI 內嵌 → 已內嵌在 `index.html`
- 外部資源只能走 CDN（瀏覽器 OCR 的 tesseract.js 就是這樣載入的）

## 注意事項

- `app.js` 裡的 `LAWS` 對照表是給「免費 AI 模式」用的，
  內容需與 `../regulations.json` 的法條保持一致。
- 修改 `../regulations.json`（法條或關鍵字）後，**必須關掉 exe 重開**才會生效。
