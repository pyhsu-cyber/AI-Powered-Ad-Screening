違規廣告快篩使用說明書

上傳一張廣告截圖，自動讀出圖上的字、比對 540 個違規用語、 列出涉違反的法條與罰則，並生成可直接寄給衛生局的陳情信。

這套工具在做什麼

它把「看到一則可疑廣告」到「送出一封格式正確、法條引用正確的檢舉信」這段流程， 從人工翻法規壓縮到幾分鐘。涵蓋食品、健康食品、化粧品、藥品、醫療器材五類廣告。

請先理解這件事

這是初篩工具，不是裁決系統。它只告訴你「這句話可能有問題、可能違反哪一條」， 最終違規認定以主管機關為準。所有自動判定的結果——辨識出來的文字、產品名稱、 產品類別——都可以也應該由你檢查修改後再送出。

設計上刻意寧可多列一項讓你排除，也不要漏掉違規句， 所以看到不太確定的項目是正常的，請自行判斷後刪減。

三步驟開始

雙擊 違規廣告快篩.exe

會跳出一個黑色視窗——那是程式本體，請不要關掉。 瀏覽器會自動開啟操作頁面。

看到藍色警告視窗時點「仍要執行」

因為這支程式沒有購買數位簽章，Windows 第一次執行會攔一下。 點「其他資訊」→「仍要執行」即可。

瀏覽器沒自動開就手動開

網址是 http://localhost:8765。要結束程式，關掉那個黑色視窗就好。

操作流程

畫面上方的 STEP 1–4 指示器會跟著你的進度亮起。

上傳廣告素材

三種方式都可以：點擊上傳區選檔、把圖直接拖進來、或按 Ctrl + V 貼上剛截的圖（不用先存檔）。

支援 JPG / PNG / WebP / GIF / BMP，單張上限 10 MB。 沒有圖也沒關係——可以直接把廣告文案貼到「廣告文字」欄位。

按「開始快篩分析」

程式會用 Windows 內建 OCR 讀出圖上的字（約 1 秒），填進「廣告文字」欄位， 再比對法規關鍵字，列出違規點與引用法條。

接著它會在背景用第二套 OCR 再讀一次做交叉比對。 如果補抓到新的違規，結果會自動更新並提示你。

這一步請務必做

OCR 難免有錯字。請看一下「廣告文字」欄位的內容對不對， 有錯可以直接在欄位裡改，改完再按一次「開始快篩分析」， 系統會用你改過的文字重新比對，不會蓋掉你的修正。

填檢舉資料

產品名稱會自動帶入辨識文字的第一行、發現日期預設今天，兩者都可以改。

然後填受文機關（22 縣市衛生局）、刊登平台、廣告網址、你的姓名與聯絡方式。

產品類別一定要選對

這個欄位決定陳情信引用哪一部法規。免費模式的系統認不出產品類別， 預設是「無法判定」（會沿用食安法）。檢舉化粧品廣告卻沒改成「化粧品」， 信裡就會引到錯的法條與錯的罰鍰金額，送件可能被退補正。

生成陳情信 → 列印或存成 PDF

按「生成陳情信」預覽全文，確認無誤後「列印 / 存成 PDF」，或「複製全文」貼到 衛生局的線上陳情表單。記得一併附上廣告截圖當證據。

兩套辨識引擎

兩套引擎讀錯的地方不一樣，所以合併使用抓得比較全。你不需要選，系統會自動安排。

引擎角色速度需要什麼
Windows 內建 OCR 主要，預設使用 約 1 秒 完全離線，不需下載
瀏覽器 OCR 備援＋背景交叉比對 約 5 秒 第一次需連網下載模型約 9 MB，之後會快取

它們什麼時候各自出場

  • 正常情況：Windows OCR 先出結果 → 瀏覽器 OCR 在背景補漏
  • Windows OCR 不能用時（缺中文 OCR 語言套件、ocr.ps1 被防毒擋下、 或跑的是舊版程式）：自動改用瀏覽器 OCR，不會整個卡住
  • 覺得還有漏字：按文字框上方的「用瀏覽器 OCR 再補一次」， 結果會附加在原本文字後面，不是取代
兩套都讀不好時

用 Win + Shift + S 截圖，在跳出的「剪取工具」視窗點 「文字動作」，可以直接複製圖片上的文字，再貼到「廣告文字」欄位。

產品類別與法條

同一句「宣稱療效」，不同產品類別引用的法律和罰鍰級距完全不同。 你在 STEP 3 選的產品類別會決定這件事，違規清單和陳情信會即時跟著換。

藥品與醫療器材本來就可以宣稱療效，它們的違規點在於 「廣告未經核准或超出核准範圍」，所以對應的是廣告核准條文，不是療效禁止條文。

陳情信

依公文陳情信慣例產出，包含受文者、主旨、說明一～五、檢舉人、聯絡方式、陳情日期（民國年）。

  • 說明二逐條列出違規事實，每條含引用原句、違規分類、理由、涉違反法條與罰則
  • 說明四自動計算檢附截圖份數
  • 說明五的檢舉獎勵辦法名稱會跟著產品類別調整，化粧品不會誤引食安法的獎勵辦法

列印會自動轉成白底黑字，畫面是深色的沒關係，印出來是正常文件。

寄送方式：各縣市衛生局的線上陳情系統、衛福部食藥署陳情檢舉信箱，或書面郵寄。

維護違規關鍵字

用記事本打開 regulations.json，在 demo_keywords 底下有兩類：

分類意義目前數量
medical_efficacy宣稱醫療效能168
exaggeration誇大不實170
改完必須重開程式

regulations.json 是程式啟動時載入一次的。 改完只重整網頁不會生效，要把黑色視窗關掉再重新執行 exe。

新增關鍵字的五條規則

比對是純字串比對，沒有語意判斷，所以有幾個容易踩的坑：

規則原因與例子
不要 收錄包含既有關鍵字的詞 清單已有「治療」，再加「治療糖尿病」，同一句話會被算成兩筆違規
不要 把同一個詞放進兩類 同樣會被算成兩筆
不要 收錄法規允許的宣稱 「養顏美容」「調整體質」「淡化細紋」「緊緻毛孔」「美白」都是法規明文允許的， 收了會把合法廣告判成違規
不要 收錄太通用的詞 「改善」「有效」「健康」會到處誤判
要 用裁處書原文測試 最容易犯的錯。裁處書寫「骨頭的一個磨損」，你收「骨頭磨損」就永遠比對不到。 請改收較短、穩定的詞（「磨損」）

每個關鍵字的法規依據、來源與真實裁罰案例，都記在 說明文件/關鍵字來源.md。

常見問題

上傳圖片後沒反應？

上傳只是載入圖片，要按「開始快篩分析」才會辨識。 按了之後若一直轉圈，看一下狀態列的文字，通常會說明卡在哪一步。

辨識出來的字很多錯，或根本讀不到？

依序試：① 按「用瀏覽器 OCR 再補一次」；② 用原圖而不是縮圖（解析度低於 600px 會提醒你）； ③ 用「剪取工具 → 文字動作」複製文字後手動貼上。

改了 regulations.json 卻沒變化？

要關掉程式重開。重整網頁沒有用。

陳情信引用的法條看起來不對？

檢查 STEP 3 的「產品類別」有沒有選對。預設是「無法判定」，會沿用食安法。

按「複製全文」沒有反應？

瀏覽器在視窗失焦時會拒絕存取剪貼簿。畫面會提示你改用手動選取後按 Ctrl + C。

介面改了卻沒更新？

在瀏覽器按 Ctrl + F5 強制重新載入。

想要更聰明的判讀？

免費模式只抓「字面上」出現的違規詞，像「讓你告別藥罐子」這種暗示療效卻沒有關鍵字的句子抓不到。 若要語意判讀，在程式資料夾建立 api_key.txt，內容貼上 Anthropic API 金鑰 （sk-ant- 開頭）後重新啟動。

注意

API 金鑰等同密碼且按使用量計費，請勿外流。 啟用後廣告截圖會傳送到外部 AI 服務，含個資的畫面請不要上傳。

資料與隱私

  • 免費模式全程在你的電腦上執行，廣告圖片不會離開這台機器
  • 檢舉人姓名、電話、Email 只存在瀏覽器記憶體，不會上傳也不會存檔
  • 只有在你主動設定 API 金鑰、啟用 AI 模式時，截圖才會傳送到外部服務
  • 程式沒有連外統計、沒有使用紀錄回傳

檔案結構

違規廣告快篩.exe 主程式，雙擊這個 ocr.ps1 Windows 內建 OCR 腳本 regulations.json 法規與違規關鍵字資料庫 static/index.html 操作介面 功能使用說明書.html 本文件 使用說明.txt 純文字版快速說明 SPEC/ 需求規格書 說明文件/ 版本紀錄、關鍵字來源與依據 測試資料/ 六張測試圖與預期結果 實作作業/ 前端原始碼與建置腳本 設計素材/ logo 與介面設計參考 版本封存/ 各版本壓縮檔
搬移時注意

前四項（exe、ocr.ps1、regulations.json、static 資料夾） 必須維持現在的相對位置，程式才找得到。其餘資料夾只是文件與素材，刪掉不影響執行。

要改介面請改 實作作業/ 裡的原始檔，改完執行 python build.py； 直接改 static/index.html 會在下次建置時被覆蓋。
