## 二、資料來源

1. **衛福部食藥署「食品標示宣傳或廣告詞句涉及誇張易生誤解或醫療效能之認定基準」**（105.6.17 部授食字第1051201580號令修正）—— 官方逐條例示詞句與 Q&A
2. **「食品及相關產品標示宣傳廣告涉及不實誇張易生誤解或醫療效能認定準則」**（109.8.4 修正，111.7.1 施行）—— 含附件一（通常得使用之詞句）、附件二（營養素生理功能詞句）
3. **「化粧品標示宣傳廣告涉及虛偽誇大或醫療效能認定準則」**（108.7.1 施行）—— 附件一（影響生理機能／改變身體結構，34條）、附件四（其他醫療效能，20條）
4. **衛福部105.9.6 部授食字第1051607584號公告**「化粧品得宣稱詞句例示及不適當宣稱詞句例示」
5. **食藥署115年（2026）5月食品廣告指引** —— 點名血濁、肝火、清肺、養肝、降三高、修復神經、機能回春、逆轉肌齡等高風險用語
6. **健康食品管理法第6條**與衛福部公告之 13 項保健功效項目（一般食品不得宣稱）
7. **各縣市衛生局裁處新聞稿**：高雄、台北、新北、桃園、台中
8. **食藥署 111～113 年度十大違規食藥廣告名單**

## 三、維護規則（重要，實測所得）

比對引擎是**純子字串比對**（`if 關鍵字 in 廣告文字`），沒有斷詞也沒有語意判斷。新增關鍵字前務必注意：

| 特性 | 實測結果 | 新增關鍵字時 |
|---|---|---|
| 重疊詞 | 清單同時有「治療」與「治療糖尿病」時，一句「可治療糖尿病」會被算成**兩筆**違規 | 不要收錄包含既有關鍵字的詞 |
| 同詞跨兩類 | 同一個詞放在兩個分類會被算成**兩筆** | 一個詞只能歸一類 |
| 同詞重複出現 | 同一個詞在文中出現三次，只算一筆 | 無須處理 |
| 英數大小寫 | 敏感（`PM2.5` 比對不到 `pm2.5`） | 英文詞需考慮大小寫變體 |
| 全形字元 | 後端比對不到全形數字；前端 `tidyCJK()` 已先轉半形 | 統一收半形 |
| 空白 | 字間有空白會比對失敗；OCR 結果已由前端還原 | 關鍵字本身不要含空白 |
| **載入時機** | `regulations.json` 於 **exe 啟動時載入一次** | **改完必須關掉程式重開**，重整網頁沒用 |

另外，**法規明文允許的宣稱用語絕對不能收**（例如「養顏美容」「調整體質」「淡化細紋」「緊緻毛孔」「美白」），
否則合法廣告會被誤判。詳見第六節。

## 六、刻意排除的詞（收了會誤判合法廣告）

這些詞在研究過程中被評估後**故意不收**，日後若想加入請先確認理由是否仍成立。

| 詞 | 不收的理由 |
|---|---|
| `美白` | 化粧品得合法宣稱「美白」（須為核准之含藥化粧品或依化粧品法規範），子字串比對會大量誤判；且現有清單已有「7天美白」「快速變白」等具體誇大寫法。食品廣告宣稱美白雖屬違規，但建議改用「美白回春」等組合詞 |
| `淡斑` | 現有關鍵字已有「立即淡斑」，若再收「淡斑」，同一句「立即淡斑」會被計算成兩筆違規 |
| `抗氧化` | 認定準則附件二明定維生素C、維生素E含量足夠時可合法宣稱「具抗氧化作用」，收錄會誤判合法文案 |
| `增加飽足感` | 認定準則附件二明定膳食纖維可合法宣稱「增加飽足感」 |
| `促進鐵吸收` | 同時是健康食品保健功效項目（違規）與附件二維生素C合法詞句「促進鐵的吸收」，兩者僅一字之差，極易誤判 |
| `三高` | 僅兩字且屬中性族群描述用語（如衛教文章「三高族群」），單獨收錄誤判率高。已改收「降三高」「降低三高」 |
| `和胃` | 官方中藥材效能例示，但「溫和胃部」「柔和胃腸」等一般敘述會被誤命中（溫[和胃]部） |
| `強心` | 官方中藥材效能例示，但「增強心肺功能」「加強心理建設」會被誤命中（增[強心]肺） |
| `療效` | 免責聲明「本產品非藥品，無療效」會被誤判成違規，反向命中合規文案 |
| `見效` | 過於通用，且已收「一週見效」。單收「見效」會命中「見效快」等大量非食品語境 |
| `改善睡眠` | 附件一合法用語「幫助入睡」語意極相近，邊界模糊；已改收明確違規的「改善失眠」「治失眠」 |
| `活化` | 現有清單已有「活化細胞」，且附件二合法詞句含「活化肝臟與血液中的凝血蛋白質」「活化凝血酶元轉變為凝血酶」，收錄會誤判 |
| `修復` | 現有清單已有「修復受損細胞」，且附件二蛋白質合法詞句含「有助於組織的修復」 |
| `白內障` | 疾病名稱單獨出現可能是衛教內容或免責聲明；已改收「告別白內障」「改善白內障」 |
| `青光眼` | 同上，疾病名稱單獨收錄誤判率高；已改收「改善青光眼」 |
| `本草綱目` | 認定基準明示引用典籍但未述及醫藥效能者為合法（例：「本草綱目」記載梅子氣味甘酸，可生津解渴）。須「引用典籍＋述及醫藥效能」才違規，單純子字串比對無法判斷 |
| `健康` | 「健康維持」為附件一合法用語；認定準則第4條第2項雖規定以「健康」為品名之一部分屬易生誤解，但該判斷需區分品名與內文，子字串比對做不到 |
| `抗UV` | 食品宣稱抗UV屬違規（115年指引明列），但化粧品／防曬產品此為合法宣稱，混用於同一資料庫會誤判 |
| `調整體質 / 養顏美容 / 幫助消化 / 滋補強身 / 增強體力 / 促進新陳代謝 / 退火 / 降火氣 / 潤喉 / 生津止渴 / 營養補給 / 幫助入睡 / 青春美麗 / 使排便順暢 / 調節生理機能` | 以上全部列於認定準則附件一「通常得使用之詞句」，為明文合法用語，絕對不可收錄（此列為提醒，非單一關鍵字） |

## 八、已知限制

1. **只抓字面**。食藥署115年指引明示違規採「整體表現綜合判斷」，隱喻、暗示、諧音、錯別字都可能違規
   （例如以「管路」影射血管、以「壞東西」影射癌細胞）。這類表達純字串比對抓不到。
2. **改寫過的說法一定比對不到**。例如原本收「骨頭磨損」，但裁處書原文是「骨頭的一個磨損」，
   中間隔了字就完全命中不了；「膝蓋不會痛」對上原文「膝蓋骨完全就不會有痛的感覺」也是一樣。
   新增關鍵字時請務必**用裁處書原文去測**，並改收較短、穩定的錨點（例如「磨損」「不會有痛」）。
3. **後端一律回食安法，前端已依產品類別改寫**。示範模式的 exe 不論產品類別都回傳食安法第28條，
   前端會依 Step 3 的「產品類別」自動改成正確法條（見第一之二節對照表）。
   **產品類別一定要選對**，選錯陳情信就會引到錯的法源與罰則級距。
4. 本工具定位為**初篩**，命中後仍須人工複核；最終違規認定以主管機關為準。
