【怎麼開始】
1. 雙擊「違規廣告快篩.exe」
   → 會跳出一個黑色視窗（程式主體，請勿關閉），瀏覽器會自動打開操作頁面。
   → 若瀏覽器沒自動開，手動開 http://localhost:8765
2. 第一次執行 Windows 可能跳出藍色警告視窗（因為程式未購買數位簽章）：
   點「其他資訊」→「仍要執行」即可。
3. 要結束程式，關閉黑色視窗即可。


【操作流程】
  STEP 1  上傳廣告截圖（點選、拖曳，或直接按 Ctrl + V 貼上）
          ↓
  STEP 2  按「開始快篩分析」
          → 自動用 Windows 內建 OCR 讀出圖上的字，填入「廣告文字」欄位
          → 比對法規關鍵字，列出違規點與引用法條
          → 接著會在背景用第二套 OCR 再讀一次做交叉比對，
            若補抓到新的違規會自動更新結果並提示你
          ↓
          ★ 請務必檢查「廣告文字」內容是否正確。OCR 難免有錯字，
            可直接在欄位裡修正，改完再按一次「開始快篩分析」。
          ★ 覺得有漏字：按「用瀏覽器 OCR 再補一次」，用另一套引擎
            再讀一遍並把結果合併，兩邊互補、抓得更全。
          ↓
  STEP 3  確認產品名稱（已由 OCR 第一行帶入，可改）、
          ★選對「產品類別」★，填檢舉人與廣告來源資料 → 生成陳情信

          ※ 產品類別會決定陳情信引用哪一部法規：
              食品     → 食品安全衛生管理法 第28條
              健康食品 → 健康食品管理法 第14條
              化粧品   → 化粧品衛生安全管理法 第10條
              藥品     → 藥事法 第66條（廣告須事前核准）
              醫療器材 → 醫療器材管理法 第41條（廣告須事前核准）
              其他／無法判定 → 沿用食安法第28條
            選錯會引到錯的法條與罰則金額，送件可能被退補正。
          ↓
  STEP 4  列印 / 存成 PDF → 寄送衛生局


【違規項目的證據等級】
  每一項違規旁邊會標一個等級，陳情信也會照這個等級調整措辭：
    有裁處案例   該用語已有主管機關實際裁處的案例，信中會直接出示案例
    法規明文例示 認定基準／準則白紙黑字列為違規詞句，信中引述法規依據
    疑似・待認定 只是依法規條文研判，沒有明文例示也沒有個案。
                 信中會寫明「係檢舉人研判之疑似違規，惠請貴局本於職權認定」，
                 不會講得像已經定讞。
  目前 718 個關鍵字中，有裁處案例 286、法規明文 361、僅供研判 71。


【本工具抓不到的四種情況】
  ★ 這些不是待修的 bug，是純關鍵字比對的先天限制，送件前請一併人工檢視。

  1. 口白內容
     電視購物、廣播、影片旁白裡的違規話術，本工具讀不到——
     只有 OCR（讀圖上的字），沒有語音辨識。
     實際裁處案例中確有違規詞句只存在於口白的情形。

  2. 暗示與整體表現
     食藥署認定基準明示違規採「整體表現綜合判斷」。
     不含關鍵字但整體傳達療效的句子（例如「告別藥罐子」、
     以「管路」影射血管）抓不到。

  3. 英文大小寫
     比對區分大小寫，「FDA approved」抓得到、「FDA Approved」抓不到。
     外文宣稱請自行檢視。

  4. 醫療器材沒有官方違規詞句表
     食藥署目前只公布藥品版的不適當詞句例示，醫療器材沒有對應詞表。
     本工具的醫材詞彙取自實際裁處案例，不是官方清單，涵蓋率有限。


【不在本工具範圍的產品】
  以下三類的主管機關與法源完全不同，用本工具產出的陳情信會引錯法條、
  寫錯罰則級距、送錯機關。程式偵測到會跳警告，但仍請自行留意：

    寵物食品      動物保護法第22條之5，農業部及各縣市動物保護機關
                  罰3萬～15萬（與食安法的4萬～400萬完全不同）
    嬰兒配方食品   有專屬的促銷與廣告限制，規則型態與一般食品不同
    電子煙／加熱菸  菸害防制法，國民健康署

【辨識引擎】
● Windows 內建 OCR（預設，主要）
  離線執行、約 1 秒、不需下載也不需網路。由 ocr.ps1 負責。
● 瀏覽器 OCR（備援與補充）
  第一次使用需連網下載中文辨識模型（約 9 MB），之後瀏覽器會快取。
  當 Windows OCR 不可用時會自動接手；也可主動按按鈕用它補抓。

※ 兩套都讀不好時：用 Win + Shift + S 截圖後，在跳出的「剪取工具」視窗
  點「文字動作」，可直接複製圖片上的文字，再貼到「廣告文字」欄位。


【升級為 AI 語意分析（選用，需付費金鑰）】
  免費模式只抓「字面上」出現的違規詞，像「讓你告別藥罐子」這種
  暗示療效但沒有關鍵字的句子抓不到。
  若要語意判讀：在本資料夾建立文字檔「api_key.txt」，內容貼上
  Anthropic API 金鑰（sk-ant- 開頭），重新啟動程式即可。
  ⚠ 金鑰等同密碼且按用量計費，請勿外流。


【維護違規關鍵字】
  用記事本打開 regulations.json，在 demo_keywords 底下：
    medical_efficacy → 宣稱醫療效能（食安法28條2項，罰60萬～500萬）
    exaggeration     → 誇大不實    （食安法28條1項，罰4萬～400萬）

  ★★ 改完必須「關掉程式再重開」才會生效，重整網頁沒有用。★★
     （regulations.json 是程式啟動時載入一次的）

  新增關鍵字的注意事項（比對是純字串比對，沒有語意判斷）：
   - 不要收錄「包含既有關鍵字」的詞。例如清單已有「治療」，
     再加「治療糖尿病」會讓同一句話被算成兩筆違規。
   - 同一個詞只能歸在一個分類，放兩邊會重複計算。
   - 不要收錄法規明文允許的宣稱用語（食品的「養顏美容」「調整體質」、
     化粧品的「淡化細紋」「緊緻毛孔」），否則合法廣告會被誤判。
   - 同一個詞在不同品類可能一邊違規一邊合法（例如「美白」用在食品違規、
     用在化粧品合法）。這種詞要另外登記在 keyword_scope 的
     cosmetic_only / food_only 底下，程式才會只在該品類套用。
   - 不要收錄太通用的詞（例如「改善」「有效」「健康」）。
   - 關鍵字本身不要含空白；英文大小寫要一致。

  每個關鍵字的法規依據與出處，詳見 說明文件/關鍵字來源.md


【資料夾說明】
  違規廣告快篩.exe    主程式
  使用說明.txt        本檔（純文字快速版）
  功能使用說明書.html  完整圖文說明書，可離線開啟與列印

  static/index.html   操作介面
  說明文件/           版本紀錄、關鍵字來源與依據
  SPEC/               需求規格書（FR/EC/NFR/AC）
  設計素材/           logo 與介面設計參考圖
  測試資料/           六張合成測試圖 + 真實案例/ 九張（取自實際裁處案件）
  實作作業/           前端原始碼（index.html / styles.css / app.js）
  版本封存/           最近三版的壓縮檔（v6～v8）
  docs/               GitHub Pages 線上版（純瀏覽器，無需安裝）
  backend/            後端參考實作與其測試
  tests/              單元／UAT／E2E 測試
  LICENSE             授權條款（保留一切權利）

  ※ exe、ocr.ps1、regulations.json、static 資料夾必須維持現在的相對位置，
    程式才找得到，請不要搬動。其餘資料夾只是資料與原始碼，刪掉不影響執行。

  ※ 要改介面請改 實作作業/ 裡的原始檔，改完執行：
        python build.py
    才會產生實際執行的 static/index.html（直接改 static/index.html 會被覆蓋）。


【注意事項】
- AI 判定僅供參考，實際違規認定與裁罰以主管機關為準。
- 法條內容請以全國法規資料庫（law.moj.gov.tw）現行條文為準。
- 檢舉人個資僅在本機瀏覽器處理，不會上傳或儲存。
- 陳情信引用的法條由「產品類別」決定，請務必選對再生成。
